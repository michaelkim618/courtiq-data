# courtiq-data

The data files [courtiqnba.com](https://www.courtiqnba.com) reads at runtime: the day's picks, the pick log,
results, the History archive, news and blog posts. They are written by the pipeline that runs the site and
mirrored here so the site can read fresh data without being redeployed for every change.

Everything here is also served by the site itself. Informational only, not betting advice.
